### 2. Library Management System

도서 등록 및 관리를 할 수 있는 도서 관리 시스템입니다.

### Features
- 도서 등록
- 도서 검색
- 도서 목록 확인
- 도서 대출 / 반납
- 도서 삭제
- 파일 저장 기능

### Language
- Python
- C++

### Concepts Used
- Class
- Object-Oriented Programming (OOP)
- List / Vector
- File I/O
- CSV Data Management

### Description
객체지향 프로그래밍 개념을 적용하여 도서 데이터를 관리하는 프로그램입니다.
사용자의 입력을 받아 도서를 추가, 검색, 수정, 삭제할 수 있도록 구현했습니다.
