## 🛠️ 사용 기술 및 부품

* **Arduino**
* **Tinkercad Circuits**
* LED
* RGB LED
* 버튼 / 스위치
* 부저
* 가변저항
* LCD 16x2
* 포토 레지스터(CDS)
* 초음파 거리 센서
* 디지털 / 아날로그 입출력
* `tone()` 함수

## 📖 학습 내용

Arduino를 활용하여 기본적인 **디지털 입출력과 아날로그 입력**을 실습하고, LED, 부저, LCD 등의 출력 장치와 버튼, 가변저항, CDS, 초음파 센서 등의 입력 장치를 직접 제어해 보았습니다.

특히 센서의 입력값에 따라 LED의 밝기를 조절하거나, 스위치 입력에 따라 서로 다른 음을 출력하는 등 **입력 → 처리 → 출력**의 기본적인 Arduino 동작 원리를 이해하는 것을 목표로 실습했습니다.
